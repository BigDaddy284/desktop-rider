## How artwork is produced

No image-generation tool is available to the developer, so artwork is drawn by hand as vector (SVG) illustration and rendered to transparent PNG for the application. The owner judges at concept stage whether this reaches the required quality.

## The in-app stand-in

The grey card the application currently shows is drawn in XAML (`OverlayWindow.xaml`). It is a labelled stand-in, not artwork, and has no asset file.
