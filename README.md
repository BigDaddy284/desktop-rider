# Desktop Rider

Desktop Rider is a Windows 11 desktop companion: an animated cartoon motocross rider and motorcycle that live on your desktop and can chat with you through a locally hosted AI model (Ollama).

The project is in early development. Installation and usage instructions will be added here as the application takes shape.

- [DESIGN.md](DESIGN.md) describes what is being built.
- [CLAUDE.md](CLAUDE.md) describes how it is being built.
