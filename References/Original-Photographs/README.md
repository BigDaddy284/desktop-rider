# Original photographs

The owner's original reference photographs of the rider, bike and riding gear belong in the folders here:

- `Bike/`
- `Rider/`
- `Riding-Gear/`

**The photographs themselves are deliberately not committed.** This repository is public and the photographs are personal, so they are kept privately by the project owner (decision recorded on 12 November 2026). Git ignores image files placed in these folders, so a local copy can sit here safely.

A written description of what the photographs show is in [`../Annotated-References/VISUAL_REFERENCE_SUMMARY.md`](../Annotated-References/VISUAL_REFERENCE_SUMMARY.md). Original photographs must never be edited, overwritten or discarded.
