# Desktop Rider 3D – full Unity project

The whole Unity project for the 3D desktop app (version 2.5): `Assets`, `Packages` and `ProjectSettings`.
Open the `Desktop Rider 3D` folder in Unity 6000.6 (Unity rebuilds its `Library` cache the first time).
Build with **File > Build Profiles > Windows**, or the Desktop Rider editor bridge.

The models, textures and Blender source files are in `Models and graphics/` at the top of this repository:
Harvey, Louie and the sidecar (`.blend` files with their textures), the original `.glb` models and the
Blender build scripts. Exported models with their tricks are in `Assets/DesktopRider/Models`,
`Assets/DesktopRider/Louie/Models` and `Assets/DesktopRider/Sidecar`.
